1 · Где я и что дальше

Что мне делать сегодня по спринту?

Третий день спринта, первая неделя. Сегодня — стендап на 5 минут: зона на шкале, хороший момент за сутки, до трёх приоритетов (урок 1.7). В выходные — недельная рефлексия, около 20 минут (урок 1.7).

2 · Вопрос по методу

Сколько часов закладывать на спринт?

30 часов на все три проекта — это 10% бодрствования (урок 1.4). Делить можно не поровну. Если спринт первый или стресс высокий, больше не бери (урок 1.4).

3 · Острое состояние

5 · Проекты спринта

Хочу на спринт марафон, английский и досмотреть сериал.

Марафон — Драйв: это личный вызов (урок 1.5). Английский — тоже Драйв, оставь один. Сериал запоем метод в Кайф не берёт. Фундамента нет: подойдут сон, еда или движение (урок 1.5).

Как поставить

Две команды в терминале

Нужен Claude Code. Скиллу не нужны ни заметки, ни аудио: метод уже внутри, своими словами.

claude plugin marketplace add https://github.com/beCyborg/jadlis-hub.git
claude plugin install jadlis-nif@jadlis

Потом спроси в Claude Code о своём, например: /jadlis-nif:nif какую практику сделать сейчас? Код и описание — github.com/beCyborg/jadlis-nif.
